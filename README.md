# 🚀 Trackify

Trackify is a modern expense tracker PWA built using Next.js and Tailwind CSS.

## ✨ Features

- 🔐 4-digit PIN Authentication
- 💸 Add, Edit & Delete Expenses
- 📊 Expense Analytics with Charts
- 💰 Monthly Budget Tracking
- 📱 Installable PWA Support
- 🌙 Premium Dark UI
- 📂 LocalStorage Data Management
- 📅 Expense Date Tracking

## 🔮 Future Upgrades

- ☁️ Cloud Database Integration
- 🔑 User Authentication
- 📤 Expense Export (PDF/Excel)
- 🔔 Expense Reminders
- 🔄 Multi-device Sync

## 🛠️ Tech Stack

- Next.js
- React
- Tailwind CSS
- TypeScript
- Recharts
- Lucide React
- Vercel
